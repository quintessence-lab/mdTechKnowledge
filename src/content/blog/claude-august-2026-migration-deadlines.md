> ## 要点
>
> - **2026年8月は Claude 関連の移行イベントが4件集中**する。うち**1件はデータ損失を伴う**。
> - **8月17日: レガシー Workbench 廃止**。**保存済みプロンプト・変数・evals は新 Workbench で非対応**——**エクスポートしないと失われる**。同日に**実験的プロンプトツールAPI 3本**（`generate_prompt` / `improve_prompt` / `templatize_prompt`）もリタイア。**【2026-08-14更新】残り3日**——エクスポートがまだの場合は今すぐ対応してください。
> - **【2026-08-06追記・完了済み】8月5日: Claude Opus 4.1 が予定通りリタイア**（`claude-opus-4-1-20250805`）。公式ドキュメントで `Retired` ステータスを確認済み。未移行のリクエストは**エラーになります**。**単価は $15/$75 と現行 Opus の3倍**だったため、移行するだけで**コストが1/3**になる。
> - **8月19日: Claude Code 週間利用上限 +50% 措置が終了**。
> - **【2026-08-14更新】8月31日の Sonnet 5 値上げは撤回されました** — 2026-08-10 に Anthropic が **$2/$10 の恒久化**を発表し、9/1 からの $3/$15 は実施されません（8月の期限は4件→**実質3件**に）。
> - さらに **9月29日には Sonnet 4.5 のリタイア見込み**（"not sooner than" 表記）。
> - **Anthropic は将来の機能ロードマップを公開しない**方針。公式に確定日付で示されるのは**廃止・移行スケジュールだけ**で、これが実質的に唯一の「読めるロードマップ」になる。

## はじめに — 「ロードマップ」は無いが「期限」はある

Anthropic は、モデルの将来リリース計画や機能ロードマップを事前公表しません。実際、2026年7月24日の Claude Opus 5 も**前日まで告知がなく**、約2か月で4モデル目という異例のペースでした。「Anthropic 2026 ロードマップ」と題した記事は複数ありますが、**いずれも第三者による推測・整理**であり、公式のロードマップ文書ではありません。

一方で、**公式が確定日付で明示するもの**が1種類だけあります。**廃止・移行スケジュール**です。Anthropic は公開モデルのリタイアについて「**最低60日前の通知**」を方針として明記しており、Claude Platform のリリースノートと Model deprecations ページに具体的な日付が載ります。

そして**2026年8月は、その期限が4件重なる月**です。うち1件は**放置するとデータが消える**タイプの変更です。本記事では、公式情報のみを根拠に、各項目の影響範囲と対処を整理します。

## 1.【8月17日】レガシー Workbench 廃止 — 唯一「データが消える」変更

**4件のなかで最も緊急度が高い**のがこれです。他の3件は「エラーになる」「価格が変わる」ですが、**これだけは対処しないと保存物が失われます**。

### 何が起きるか

- **レガシー Workbench**（`platform.claude.com/workbench`）へのアクセスが **2026年8月17日で終了**
- 移行先は**新しい Workbench**（`platform.claude.com/playground`）
- ⚠️ **保存済みのプロンプト・変数・evals は、新 Workbench では非対応**

つまり、**単なるURL変更ではなく、保存済みデータの引き継ぎが行われません**。

### 対処（8月17日まで）

公式が案内しているエクスポート導線は2か所です。

1. **レガシー Workbench 上のバナー**からエクスポート
2. **Organizational Settings**（組織設定）からエクスポート

社内でプロンプトを Workbench に貯めている場合、**「誰が」「どこに」保存しているかが分散している可能性**がある点に注意してください。組織設定からのエクスポートで組織全体を回収できるか、個人ごとの作業が必要かを早めに確認し、**バージョン管理下のリポジトリ（`prompts/` ディレクトリなど）へ移す**のが恒久対策になります。

### 同時にリタイアする API 3本

同じ8月17日に、**実験的プロンプトツールAPI**もリタイアします。

| エンドポイント | 用途 |
|:---|:---|
| `POST /v1/experimental/generate_prompt` | プロンプトの自動生成 |
| `POST /v1/experimental/improve_prompt` | プロンプトの改善 |
| `POST /v1/experimental/templatize_prompt` | プロンプトのテンプレート化 |

**社内ツールやスクリプトがこれらを呼んでいないか、コードベースを検索**してください。`/v1/experimental/` で grep すれば一括で見つかります。

```bash
# リポジトリ全体で該当APIの利用箇所を洗い出す
grep -rn "v1/experimental/\(generate\|improve\|templatize\)_prompt" .
```

これらは "experimental" の名のとおり実験的APIであり、**代替エンドポイントは提供されません**。同等機能が必要な場合は、通常の Messages API 上に自前のプロンプト生成・改善フローを組む形になります。

## 2.【8月5日・完了済み】Claude Opus 4.1 リタイア — 移行するだけでコストが1/3に

> **【2026-08-06追記】予定通りリタイア完了を確認**: Anthropic公式の[Model deprecationsページ](https://platform.claude.com/docs/en/about-claude/model-deprecations)で、`claude-opus-4-1-20250805` のステータスが **`Retired`** になっていることを確認しました。以下は完了済みの内容として記載します。

### 対象と代替

| 項目 | 内容 |
|:---|:---|
| 対象モデル | **`claude-opus-4-1-20250805`** |
| 非推奨化の通知 | 2026年6月5日 |
| **リタイア日** | **2026年8月5日（完了済み）** |
| 公式の推奨移行先 | `claude-opus-4-8`（本記事執筆時点では **`claude-opus-5`** も同額で選択可） |

リタイア後は、**該当モデルIDへのリクエストはすべてエラー**になります。未移行のまま利用しているシステムがあれば、**既にエラーが発生している状態**です。至急移行してください。

### 見落としがちな「コスト面のボーナス」

Opus 4.1 は**旧世代の価格体系のまま**残っていたモデルです。

| モデル | 入力 / 出力（per MTok） | Opus 4.1 比 |
|:---|:---:|:---:|
| **Opus 4.1**（リタイア対象） | **$15 / $75** | — |
| **Opus 5** / Opus 4.8 / 4.7 / 4.6 / 4.5 | **$5 / $25** | **1/3** |

つまり、**移行は「やらされる作業」ではなく、コストが3分の1になる改善**でもあります。しかも Opus 5 は Opus 4.1 より大幅に高性能です。まだ 4.1 を使っている経路があるなら、**8月5日を待たずに移行したほうが得**です。

### 利用箇所の洗い出し方

公式が案内している監査手順は次のとおりです。

1. Claude Console の **Usage** ページを開く
2. **Export** をクリック
3. ダウンロードした CSV で、**APIキー別・モデル別**の利用状況を確認

これで「どのキーがまだ 4.1 を叩いているか」が特定できます。

> **移行時の注意**: Opus 4.1 → Opus 5 は世代を大きく跨ぐため、**`temperature` / `top_p` / `top_k` が 400 エラーになる**（Opus 4.7 以降で非推奨）、**thinking が既定オン**、**`thinking: disabled` は effort `high` 以下でのみ可**といった破壊的変更が積み重なります。詳細は [Claude Opus 5 完全ガイド](/mdTechKnowledge/blog/claude-opus-5-guide/) の移行チェックリストを参照してください。

## 3.【8月19日】Claude Code 週間利用上限 +50% 措置の終了

Claude Fable 5 の一連の措置に伴い、**Claude Code の週間利用上限が +50% された状態**が続いていましたが、これが **2026年8月19日で終了**します。

| 項目 | 内容 |
|:---|:---|
| 対象 | Pro / Max / Team・legacy 席課金型 Enterprise の Claude Code 利用（CLI・IDE・Desktop・Web すべて） |
| 内容 | 週間利用上限の **+50%** |
| **終了日** | **2026年8月19日** |
| 必要な操作 | **なし**（期限後は自動的に通常水準へ戻る） |

**操作は不要**ですが、**上限に近い使い方をしているチームは、8月19日以降に体感が変わります**。Claude Code をヘビーに回している場合は、この日を境に「今週分を使い切るのが早くなった」と感じる可能性があるため、**チーム内に周知しておく**とサポート問い合わせを減らせます。

なお **Claude（web/desktop/mobile）や Cowork の上限はこの措置の対象外**です。

## 4.【撤回済み】8月31日の Sonnet 5 導入価格終了 — 値上げは実施されない

> **【2026-08-14 更新】この期限は消滅しました。** 2026年8月10日、Anthropic は **Sonnet 5 の $2/$10（Batch $1/$5）を恒久価格とする**ことを発表し、9月1日からの $3/$15 への値上げは**撤回**されました。以下は経緯の記録として残します。

当初の計画では次のとおり、9月から**入力・出力ともに1.5倍**になる予定でした。

| 期間 | 入力 / 出力（per MTok） | Batch |
|:---|:---:|:---:|
| ~~〜2026年8月31日（導入価格）~~ → **恒久価格** | **$2 / $10** | $1 / $5 |
| ~~2026年9月1日〜（標準価格）~~ → 撤回 | ~~$3 / $15~~ | ~~$1.50 / $7.50~~ |

これに伴い、本章で案内していた「9月コストの試算」「値上げ分の吸収策」は**不要になりました**。Batch API（一律50%オフ）とプロンプトキャッシュ（読取は入力単価の0.1倍）が有効なコスト最適化である点は変わりません。

> 単価の全体像と「フロンティア×安価」のコスト設計は [AIトークン単価の価格破壊が止まらない](/mdTechKnowledge/blog/llm-token-price-comparison-2026/) に整理しています。

## 5.（参考）9月末: Sonnet 4.5 のリタイア見込み

8月ではありませんが、すぐ後ろに控えているので触れておきます。

| モデル | 現在の状態 | リタイア見込み |
|:---|:---|:---|
| `claude-sonnet-4-5-20250929` | **Active** | **2026年9月29日より前ではない** |
| `claude-haiku-4-5-20251001` | Active | 2026年10月15日より前ではない |
| `claude-opus-4-5-20251101` | Active | 2026年11月24日より前ではない |

公式表記は "**Not sooner than**"（＝この日より前にはリタイアしない）であり、**確定日ではありません**。実際にリタイアが決まると Deprecated に変わり、**最低60日前に通知**されます。

とはいえ、**Sonnet 4.5 を本番で使っている場合は「秋には移行が必要になる」前提**で計画しておくのが安全です。Sonnet 5 への移行は破壊的変更を伴う（`budget_tokens` 削除・非既定のサンプリングパラメータで400・新トークナイザで約30%トークン増）ため、直前対応には向きません。

## 対応の優先順位（推奨）

期限と「放置した場合の損害」で並べると、優先順位は明確です。

| 優先 | 項目 | 理由 |
|:---:|:---|:---|
| **1** | **Workbench のエクスポート**（8/17） | **唯一のデータ損失リスク**。しかも復旧手段がない |
| **2** | **`/v1/experimental/*_prompt` の利用箇所調査**（8/17） | 動いているツールが**同日に壊れる**。代替APIなし |
| **3** | **Opus 4.1 の利用箇所調査と移行**（8/5） | **最も期限が早い**。かつ移行でコスト1/3という利得もある |
| ~~4~~ | ~~Sonnet 5 の9月コスト試算（8/31）~~ **→ 不要（値上げ撤回）** | 2026-08-10 の恒久価格化により試算自体が不要に |
| 5 | Claude Code 上限終了の周知（8/19） | **操作不要**。事前周知だけで足りる |

**1と2は同じ8月17日**なので、まとめて着手するのが効率的です。「Workbench を開いてエクスポート → コードベースを grep」で、両方を1回の作業で片付けられます。

## まとめ

- Anthropic は**将来の機能ロードマップを公開しない**が、**廃止・移行スケジュールは公式に確定日付で示される**。これが実務上「読める唯一のロードマップ」になる。
- **2026年8月は移行イベントが4件集中**（→ Sonnet 5 値上げの撤回で**実質3件**に）。うち **8/17 の Workbench 廃止だけがデータ損失を伴い、復旧手段がない**——最優先で対処すべき。
- **8/5 の Opus 4.1 リタイアは、単価 $15/$75 → $5/$25 の移行**でもある。期限対応であると同時にコスト削減施策として扱える。
- **8/19（Claude Code 上限）は壊れないが体感が変わる**。事前周知で驚きを防げる。**8/31 の Sonnet 5 値上げは撤回された**（$2/$10 恒久化・2026-08-10 発表）。
- 秋以降も **Sonnet 4.5（9/29〜）・Haiku 4.5（10/15〜）・Opus 4.5（11/24〜）** が控える。**Model deprecations ページを定期的に確認する運用**を、チームのルーティンに組み込んでおくのが結局いちばん安上がりになる。
