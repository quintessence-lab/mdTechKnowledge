> ## 要点
>
> - **現行の4系統**: 最上位 **Fable 5.1（$10/$50）**、主力上位 **Opus 5.5（$4/$20）**、バランス型 **Sonnet 5.5（$2/$10）**、軽量 **Haiku 5.5（$0.10/$0.50）**。単位はすべて per MTok（100万トークン）で、**入力／出力**の順です。
> - **2026-10-07 に Haiku 5.5 が登場**し、軽量モデルの単価が Haiku 4.5（$1/$5）から **10分の1**になりました。ただし **100,000トークン超のプロンプトは $0.50/$2.50 の2段階価格**で、さらに**新トークナイザーで同じ文章が約30%多いトークン**に数えられます。
> - **キャッシュ読取は「入力の0.1倍」が標準**ですが、**Opus 5.5・Sonnet 5.5 は0.05倍**、**Fable 5.1・Mythos 5.1 は0.025倍**です。Sonnet 5.5 は 10/7 に読取が $0.20 → **$0.10** へ下がりました。
> - **Batch API は入出力とも一律50%オフ**。キャッシュ・データ所在地の倍率とも**重ねて**効きます（fast mode とは併用不可）。
> - **サーバーツールの追加料金**は、**Web検索が1,000回あたり $10**。Web fetch は追加料金なし、コード実行は Web検索／fetch と併用なら無料です。
> - **Max 5x／20x と Team プランには月次 API クレジット**（$100／$200／席あたり $20〜$100）が付きます。Claude Code には使えない点に注意してください。

## 3. 単価に重なる「修飾子」

標準単価に、次の修飾子が**乗算で重なります**。

### 3-1. Batch API — 入出力とも一律50%オフ

| モデル | Batch 入力 | Batch 出力 |
|:---|:---:|:---:|
| Fable 5.1 / Fable 5 / Mythos | $5 | $25 |
| Opus 5.5 | $2 | $10 |
| Opus 5 / 4.8 / 4.7 / 4.6 / 4.5 | $2.50 | $12.50 |
| Sonnet 5.5 / Sonnet 5 | $1 | $5 |
| Sonnet 4.6 / 4.5 | $1.50 | $7.50 |
| Haiku 5.5（100Kトークン以下） | $0.05 | $0.25 |
| Haiku 5.5（100Kトークン超） | $0.25 | $1.25 |
| Haiku 4.5 | $0.50 | $2.50 |

Batch は即時応答が不要な大量処理（夜間の一括分類・要約、評価の一括実行など）向けです。Message Batches API では、Opus 5.5・Opus 5・Sonnet 5.5・Sonnet 5・Haiku 5.5 などが最大 **300k 出力トークン**（ベータヘッダー `output-300k-2026-03-24`）に対応します。

### 3-2. プロンプトキャッシュ

| 操作 | 倍率（入力単価に対して） |
|:---|:---|
| 5分キャッシュ書込 | 1.25倍 |
| 1時間キャッシュ書込 | 2倍 |
| キャッシュ読取（ヒット） | 標準 **0.1倍**。**Opus 5.5・Sonnet 5.5 は0.05倍**、**Fable 5.1・Mythos 5.1 は0.025倍** |

5分キャッシュは**1回読めば元が取れ**、1時間キャッシュは**2回読めば元が取れます**（公式の整理）。キャッシュの倍率は Batch 割引・データ所在地の倍率と**重ねて**適用されます。

### 3-3. fast mode（リサーチプレビュー）

| モデル | 入力 | 出力 |
|:---|:---:|:---:|
| Opus 5.5 | $8 | $40 |
| Opus 5 / Opus 4.8 | $10 | $50 |

いずれも標準単価の2倍で、出力が最大2.5倍速くなります。**Claude API（直接）のみ**で利用でき、Bedrock・Google Cloud・Foundry・Claude Platform on AWS では使えません。**Batch API とは併用できません**。キャッシュとデータ所在地の倍率は重ねて適用されます。

### 3-4. データ所在地（米国内限定推論）

Claude 4.6 以降で `inference_geo: "us"` を指定すると、**入力・出力・キャッシュ書込・キャッシュ読取のすべてが1.1倍**になります（Haiku 5.5 は100K超の高い単価にも適用）。グローバルルーティング（既定）は標準単価です。Bedrock と Google Cloud はパートナー側の独自のリージョン価格になります。

### 3-5. 長いプロンプトと Haiku 5.5 の2段階価格

Claude 4.6 以降のモデル（Haiku 5.5 を除く）は、**1M トークン全体が標準単価**です（9k トークンのリクエストと 900k トークンのリクエストで、1トークンあたりの単価は同じ）。**Haiku 5.5 だけ**は、リクエストのプロンプト長（キャッシュ読取・書込を含む全入力）が **100,000トークンを超えると高い単価**になります。判定は**リクエストごと**で、超えたリクエストだけが高くなり、過去のリクエストの請求は変わりません。キャッシュにヒットしている部分があっても、全体が100Kを超えれば高い単価です。

### 3-6. 新トークナイザー — 同じ文章が約30%多いトークンに

**Claude 4.7 以降のモデル**（Opus 4.7 以降、Sonnet 5 以降、Haiku 5.5 など）は新しいトークナイザーを使い、**同じ文章で約30%多いトークン**になります（増え方は内容による）。Sonnet 4.6 以前や Haiku 4.5 は従来のトークナイザーです。**単価が同じでも、旧モデルから移ると請求トークン数が増える**ことを見積もりに入れてください。

## 4. ツール利用の追加料金

ツールを使うと、通常のトークン料金に次が加わります。

| 項目 | 内容 |
|:---|:---|
| **Web検索** | **$10 / 1,000回**（検索結果は入力トークンとしても課金）。エラー時は課金されない |
| **Web fetch** | **追加料金なし**（取得した内容のトークン分のみ）。`max_content_tokens` で上限指定を推奨 |
| **コード実行** | Web検索／Web fetch（`_20260209` 以降）と併用なら**無料**。単独では実行時間課金（最低5分、**組織あたり月1,550時間まで無料**、超過は**$0.05 / コンテナ時間**） |
| **ツール使用のシステムプロンプト** | `tool_choice` が auto／none のとき、Opus 5.5・Sonnet 5.5・Haiku 5.5 で **286トークン**（Haiku 4.5 は496、Sonnet 4.6 は497）が入力に加算 |
| **bash ツール** | 定義だけで追加 **325トークン**（Claude 4.7 以降。4.6 以前は244） |
| **text editor ツール** | 追加 **974トークン**（Claude 4.7 以降。4.6 以前は745） |
| **computer use / browser use** | `computer_toolset_20260801`／`browser_toolset_20260801` の宣言で**約4,500入力トークン**が加算 |
| **Claude Managed Agents** | トークンは通常単価＋**セッション時間 $0.08 / 時間**（`running` 状態のみ計上。idle は計上されない）。Batch 割引は適用されない |

Managed Agents では、米国内限定推論の1.1倍や fast mode の割増が適用されます。詳細は [Claude Managed Agents 簡易ガイド](/mdTechKnowledge/blog/claude-managed-agents-guide/) を参照してください。

## 5. 試算例

### 5-1. 大量分類 — Haiku 4.5 から Haiku 5.5 へ

前提: **100万リクエスト**、1件あたり入力2,000トークン・出力200トークン（Haiku 4.5 のトークナイザーで計測）。Haiku 5.5 では新トークナイザーで**約30%増**（入力2,600・出力260）、いずれも100K以下とします。

| 構成 | 入力 | 出力 | 合計 |
|:---|:---:|:---:|:---:|
| Haiku 4.5（標準） | 2,000 MTok × $1 = $2,000 | 200 MTok × $5 = $1,000 | **$3,000** |
| Haiku 5.5（標準） | 2,600 MTok × $0.10 = $260 | 260 MTok × $0.50 = $130 | **$390** |
| Haiku 5.5（Batch） | $130 | $65 | **$195** |

名目の単価は10分の1ですが、トークン増の分を織り込むと**約87%減**（$3,000 → $390）です。Batch が使えれば、さらに半額になります。これは試算で、実際のトークン増加率は内容によって変わります。**自社データで `count_tokens` により再計測**してください。

### 5-2. 長いシステムプロンプトのキャッシュ — Sonnet 5.5

前提: **50,000トークンの共通プロンプト**を、5分以内の間隔で**1,000リクエスト**送る（キャッシュが切れない場合）。

| 構成 | 計算 | 合計 |
|:---|:---|:---:|
| キャッシュなし | 50 MTok × $2 | **$100** |
| キャッシュあり | 書込1回（0.05 MTok × $2.50 = $0.125）＋読取999回（0.05 MTok × $0.10 × 999 ≒ $4.995） | **約 $5.12** |

読取が0.05倍の Sonnet 5.5 では、共通プロンプトが長いほどキャッシュの効果が大きくなります（この例では約95%減）。ユーザー入力や出力のトークン分は別途かかります。

## 7. サブスクのAPIクレジットとの関係

2026-10-07 から、**Max 5x／Max 20x／Team**（割引Teamを含む）の契約者は、Claude Console 組織をリンクすると**月次の API クレジット**を受け取れます。

| プラン | 月次クレジット |
|:---|:---|
| Max 5x | $100 |
| Max 20x | $200 |
| Team（Standard 席） | 席あたり $20（全席プール、上限 $500） |
| Team（Premium 席） | 席あたり $100（全席プール、上限 $500） |

対象は **Claude API・Managed Agents・Agent SDK・Playground** で、**Claude Code とアプリ内の追加利用には使えません**。未使用分は請求サイクル末に失効し、繰り越せません。Free・Pro・Enterprise は対象外です。受け取り手順は [【2026年9月版】Claude 全プラン費用比較](/mdTechKnowledge/blog/claude-plans-cost-comparison-2026-09/) の第8章を参照してください。

## 8. 見積もり時の注意点

- **名目単価だけで比較しない**: 新トークナイザー（約30%増）、Haiku 5.5 の100K超2段階価格、思考トークン（出力として課金）を織り込んでください。
- **Sonnet 5.5・Opus 5.5 は「読取が安い」モデル**: 共通プロンプトが長いワークロードほど、キャッシュを前提にした設計が効きます。
- **修飾子は乗算**: Batch × キャッシュ × データ所在地（1.1倍）は重ねて適用されますが、fast mode と Batch は併用できません。
- **価格は頻繁に改定されます**: 必ず公式 pricing ページで最終確認してください。他社を含む横断比較は [AIトークン単価の価格破壊が止まらない](/mdTechKnowledge/blog/llm-token-price-comparison-2026/)、モデル選択の実務は [Claude Opus 5 リリースで変わった単価とモデル選択](/mdTechKnowledge/blog/claude-opus-5-pricing-and-model-selection/) を参照してください。
