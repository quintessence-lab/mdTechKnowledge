> ## 要点（2026年7月度の結論）
>
> - **Pro（月額）**: **iPhone（App Store）が微安**。iOS は ¥3,000 固定、Web は $20 のドル建て＋消費税で実質 約¥3,570。**月 約¥570（約16%）iOS が安い**
> - **Max 5x / 20x**: **Web（claude.com）一択**。iOS は円建て実額で約12%（USD 構造では +25%）割高。**月 ¥2,100〜¥4,300 の差**
> - **年契約は Web のみ実質有利**: Pro 年契約は Web $200 / iOS $214.99（+7.5%）。**Max の年契約は iOS に存在しない**
> - **法人・経費処理は Web 一択**（iOS は Apple 名義の領収書のみでインボイス対応に難）
> - 7月は料金表自体の変動はなかったが、**7月20日に Fable 5 が Max / Team Premium へ恒久組み込み**（追加費用なし）となり、**同じ月額で得られる価値がプラン間で大きく動いた**月だった

本記事は **2026年7月度の月次記録版**です。7月時点の確定値（為替・App Store 円価格・税制・プラン内容）を固定して残します。常に最新の状態へ更新される比較は、以下の既存記事を参照してください。

**前提（7月度の固定値）**: 為替 **$1 ≈ ¥162.4**（7月上旬〜中旬は概ね ¥161〜163）。Web は2026年4月以降**消費税10%**が加算（Anthropic は適格請求書発行事業者）。iOS は2026年6月の **Apple 円ティア引き下げ後**の価格（Pro ¥3,400→¥3,000・Max 5x ¥21,400→¥20,000・Max 20x ¥42,400→¥40,000）。

## 1. 契約経路は2系統ある

| 経路 | 提供者・価格の性質 |
|:---|:---|
| **Web 直接契約**（claude.com） | Anthropic が定価で提供。**米ドル建て**請求＋消費税10% |
| **iPhone アプリ契約**（App Store） | Apple の手数料（標準30%）の影響で**多くのプランが割高**。**日本円固定ティア**（税込） |

機能は**完全に同等**です（同一プランなら Web 契約でも iOS アプリ・デスクトップアプリで利用可能）。異なるのは**価格・請求通貨・領収書の名義**だけです。

なお **Team / Enterprise は App Store では契約できません**（Web・営業経由のみ）。iPhone アプリから契約できるのは Free / Pro / Max です。

## 2. 米国価格（USD）での構造比較

| プラン | Web 月額 | Web 年契約 | iOS 月額 | iOS 年契約 | iOS 割高率 |
|:---|:---|:---|:---|:---|:---:|
| Free | $0 | — | $0 | — | — |
| **Pro** | **$20** | **$17/月（$200一括）** | $20.00 | $214.99 | 月: 同額 / 年: **+7.5%** |
| **Max 5x** | **$100** | 月額のみ | **$124.99** | なし | **+25%** |
| **Max 20x** | **$200** | 月額のみ | **$249.99** | なし | **+25%** |

Apple 手数料の転嫁パターンはプランで異なります。

| プラン | Anthropic の対応 |
|:---|:---|
| Pro 月額 | **吸収**（Web と同額） |
| Pro 年契約 | **一部転嫁**（+7.5%） |
| Max 5x / 20x | **完全転嫁**（+25%） |

## 3. 日本価格（7月度・$1≈¥162.4・税込実質）

| プラン | iOS（円固定・税込） | Web 実質（$×162.4×1.10） | 差 |
|:---|:---|:---|:---|
| Pro 月額 | **¥3,000** | 約 ¥3,570 | **iOS が約 ¥570 安**（約16%） |
| Max 5x 月額 | ¥20,000 | **約 ¥17,900** | **Web が約 ¥2,100 安**（iOS 約12%高） |
| Max 20x 月額 | ¥40,000 | **約 ¥35,700** | **Web が約 ¥4,300 安**（iOS 約12%高） |

7月度のポイントは3つです。

1. **Pro の「iOS 微安」が定着** — 6月の Apple 円値下げ（¥3,400→¥3,000）と円安（$1≈¥162.4）が重なり、iOS の固定価格が Web のドル建て実質を下回る状態が7月を通して継続しました
2. **Max は円実額の差が縮小したが逆転はせず** — Apple の円値下げで差は6月版より縮まりましたが、USD 構造の +25% は不変。年換算で **Max 5x 約¥25,000・Max 20x 約¥51,000** の差になります
3. **損得は為替依存** — 円高に振れれば Web の実質コストが下がり、Pro でも Web 有利に戻ります。この結論は「$1≈¥162.4 の7月」の記録です

## 4. 7月に起きた「同じ料金で得られる価値」の変化

7月は**料金表そのものの改定はありませんでした**が、同じ月額で得られる中身が大きく動いた月でした。費用比較の観点で記録しておきます。

### 4-1. Fable 5 の扱いが最終決着（7月20日）— Max が「一番恵まれた」

| プラン | 決着内容 | 費用面の意味 |
|:---|:---|:---|
| **Max / Team Premium** | Fable 5 を**週間上限の50%として恒久組み込み** | **追加費用ゼロ**で常用可。実質的な値上げなしの増強 |
| **Pro / Team Standard** | Usage Credits（従量）継続＋**一時 $100 クレジット** | 使うなら従量負担が残る。$100 は請求期限 2026-08-02・有効期限 2026-09-17 |

月額の数字は変わらないまま、**Max の「円あたりの価値」が7月20日を境に一段上がった**ことになります。Max 5x（Web 約¥17,900）と Pro（iOS ¥3,000）の間の検討では、この差も含めて判断する必要があります。

### 4-2. Opus 5 リリース（7月下旬）

7月下旬に最上位モデル Opus 5 がリリースされました（API 価格は入力 $5 / 出力 $25 per MTok）。**サブスクリプションの月額は据え置き**のまま利用できるモデルが強化されており、これも「同じ料金で得られる価値」の増加側の出来事です。

### 4-3. （参考）8月に控えるもの

7月度時点で判明していた翌月の予定として、Claude Code 週間上限 +50% 措置の終了（8月19日）などがあります。詳細は [8月の移行期限まとめ](/mdTechKnowledge/blog/claude-august-2026-migration-deadlines/) を参照してください。

## 5. どちらで契約すべきか（7月度版マトリクス)

| ユーザー像 | 推奨 | 理由 |
|:---|:---|:---|
| 個人 Pro（月額・コスト重視） | **iPhone アプリ** | ¥3,000 固定が Web 実質（約¥3,570）より月約¥570 安 |
| 個人 Pro（年契約を検討） | **Web** | 年契約の割安幅は Web が上（$200 vs $214.99） |
| 個人 Max（5x / 20x） | **Web 一択** | 月 ¥2,100〜¥4,300 安。iOS に年契約なし。7/20 以降は Fable 5 恒久込みで価値も増 |
| 法人・経費精算あり | **Web 一択** | Anthropic 名義の領収書・インボイス対応 |
| Apple にサブスクを集約したい個人（Pro） | iPhone アプリでも可 | 7月の為替なら金額面の不利もない |
| Team / Enterprise | **Web / 営業経由のみ** | App Store では契約不可 |

> 最もコスパの良い構成は **「Web で契約して、iPhone アプリで使う」**（Max の場合）。契約経路とアプリ利用は独立しています。

## 6. 注意点

- **契約経路の移管は不可** — iOS ⇄ Web の切り替えは「解約 → 新規契約」が必要
- **iOS の領収書は Apple 名義のみ** — 法人の経費処理・インボイスには不向き
- **為替で結論が変わる** — 本記事の Pro「iOS 微安」は $1≈¥162.4 時点の記録。円高局面では Web 有利に戻る
- **課金分離は一時停止のまま** — 2026年6月15日に施行予定だった Agent SDK / `claude -p` 等の課金プール分離は施行当日に一時停止され、7月度も再開されなかった（比較への影響なし）

## まとめ

2026年7月度の Claude プラン費用は、**「Pro は iPhone、Max は Web」**という住み分けが為替と Apple の円値下げによって固定化した月でした。同時に、7月20日の Fable 5 恒久組み込みで **Max の実質価値が料金据え置きのまま上昇**しており、単純な月額比較だけでなく「同じ料金に何が含まれるか」を見る必要性が増しています。最新の状況は冒頭に挙げた随時更新版の2記事で確認してください。
