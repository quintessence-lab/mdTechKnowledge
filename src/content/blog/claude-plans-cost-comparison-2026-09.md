> ## 要点（2026年9月時点）
>
> - **Pro（月額）**: **iPhone（App Store）が微安**。iOS ¥3,000 固定 vs Web 実質 約¥3,436。**月 約¥436（約13%）iOS が安い**（8月の約¥450からわずかに縮小）
> - **Max 5x / 20x**: **Web（claude.com）一択**。**月 ¥2,800〜¥5,600 Web が安い**。8月よりさらに**拡大**した
> - **拡大の理由も円高**: 9月上旬は**日銀利上げ観測＋FRB高官のドル安発言**を受けて $1≈¥156 前後（8月は約¥157）。直近1週間で約2.5%の円高が進んだ
> - **Pro 年契約は日本では「Webがやや優位」に転換**: iOS ¥35,000 vs Web 約¥34,364 で**年 約¥636 Web が安い**（8月は逆にほぼ互角〜Webがわずかに安い程度だった）
> - **法人・経費処理は Web 一択**（iOS は Apple 名義の領収書のみ）
> - **Claude Fable 5.1が9月1日にリリース**。価格はFable 5と同額（$10/$50 per MTok）だが、**サブスクプラン上の枠組みはPro/Team StandardならUsage Credits（従量課金）が前提**。**Max/Team Premiumでないと、週間上限の枠がすぐ尽きて実費課金に入りやすい**（詳細は本記事4章）

## 1. 契約経路は2系統ある

| 経路 | 価格の性質 |
|:---|:---|
| **Web 直接契約**（claude.com） | Anthropic が定価で提供。**米ドル建て**請求＋消費税10%。為替の影響を受ける |
| **iPhone アプリ契約**（App Store） | Apple 手数料の影響で多くのプランが割高。**日本円建ての固定価格**（税込）で、日々の為替では動かない |

機能は**完全に同等**です。Web で契約しても iPhone アプリ・デスクトップアプリで同一アカウントで利用できます。異なるのは**価格・請求通貨・領収書の名義**だけです。

なお **Team / Enterprise は App Store では契約できません**（Web・営業経由のみ）。iPhone アプリから契約できるのは Free / Pro / Max です。

### 8月からの変化 — 円高がさらに進み、Webの優位が全プランで拡大

| プラン | 8月（$1≈¥157） | **9月（$1≈¥156）** | 変化 |

理由は8月と同じく、**iOS は円固定・Web はドル建て**だからです。円高に振れるほどWeb側だけが安くなっていきます。

- **Pro月額**: iOS有利は続くものの、8月から約¥14円高が進んだ分だけ差が縮小。**円高がさらに進めば、いずれWebが逆転する水準**に近づいています
- **Pro年契約**: 8月時点では「ほぼ互角」でしたが、9月はWebが明確に安い側に転じました。**年契約を検討中なら、円高局面ではWeb契約の方が有利になりやすい**点に注意してください

## 4. Claude Fable 5.1 リリースとサブスクプラン上の注意点（最重要）

**2026年9月1日、Claude Fable 5 の後継モデル Claude Fable 5.1 がリリース**されました。詳細は [Claude Fable 5.1 / Mythos 5.1 完全ガイド](/mdTechKnowledge/blog/claude-fable-5-1-mythos-5-1-guide/) を参照してください。ここでは**サブスクプランでの費用に直結する部分**に絞って解説します。

### Fable 5.1の価格はFable 5と同額

| 項目 | 値 |
|:---|:---|
| 入力単価 | $10 per MTok（Fable 5と同額） |
| 出力単価 | $50 per MTok（Fable 5と同額） |
| キャッシュ読み取り単価 | **$0.25 per MTok**（Fable 5の$1から**90%削減**） |

入出力の単価自体は変わっていませんが、長時間の会話やシステムプロンプトの再利用が多い使い方ではキャッシュコストの削減効果が効いてきます。

### サブスクプラン上の扱い — Fable 5と同じ枠組みが引き継がれる想定

本記事執筆時点で、Anthropicから**Fable 5.1固有のプラン変更のアナウンスはありません**。価格が同額であることから、Fable 5と同じ以下の枠組みがそのまま引き継がれると見られます。

| プラン | 扱い |
|:---|:---|
| **Max / Team Premium** | **週間利用上限の50%として恒久的にプランへ組み込み**。クレジット不要・締切なし |
| **Pro / Team Standard** | **Usage Credits（従量メーター課金）**でのアクセス |
| **API / Claude Platform** | 従量課金（入力$10/出力$50 per MTok） |

### 【重要】ProプランでFableを使うと「すぐ枠が尽きる」理由

Fable系モデル（5・5.1とも）をPro/Team Standardで使う場合、**本格的に使い始めるとすぐに課金圏に入る**構造になっています。理由は3つです。

1. **「50%」は追加枠ではなく、既存の週間利用上限からの切り出し**。Fable系に回せるのは「Proの週間枠の半分まで」で、ボーナス容量ではありません
2. **Fable系は"重い・高い"モデル**: API換算で入力$10/出力$50（Opus 4.8の2倍の単価）。新トークナイザで同じ文章でも約30%多くトークンを消費し、想定用途も長時間・数百万トークン規模の自律タスクのため、1回の利用あたりの消費が大きい
3. **Pro/Team Standardは2026年7月20日以降、Usage Creditsが実質の枠**。かつては上限到達後は待機で済みましたが、現在は**枠を使い切った後は実費**になります

Anthropicから**$100の一時クレジット**が付与されていますが、**請求期限は2026-08-02、有効期限は2026-09-17**（本記事公開時点でまもなく失効）です。この一時クレジットを使い切った、または期限切れとなった後は、**Pro/Team StandardでFable系を使うたびに実費が発生**します。

> **結論**: ユーザーが指摘する通り、**Fable 5.1を本格的に使いたいならMax（またはTeam Premium）が現実的な選択肢**です。Proのままだと「無料で試せる少量の試用枠」程度に捉えるのが安全で、継続的な利用には向きません。厳密なしきい値は週間上限値・クレジット換算が未公表のため、**ダッシュボードでの実測が必須**です。

サブスク料金表そのもの（Web/iOSの月額・年額）は8月から**変更ありません**。9月に効いてくるのは為替の変動と、Fable系クレジットの期限です。

## 6. どちらで契約すべきか（9月版）

| ユーザー像 | 推奨 | 理由 |
|:---|:---|:---|
| 個人 Pro（月額・コスト重視） | **iPhone アプリ** | ¥3,000 固定が Web 実質（約¥3,436）より月約¥436 安 |
| 個人 Pro（年契約を検討） | **Web** | 円高でWebが年約¥636安に転じた。8月時点の「ほぼ互角」から変化 |
| 個人 Max（5x / 20x） | **Web 一択** | 月 ¥2,800〜¥5,600 安。iOS に年契約なし。円高で差はさらに拡大中 |
| **Fable 5.1 を本格的に使いたい個人** | **Max（Web推奨）** | Pro/Team StandardはUsage Credits前提ですぐ課金圏に入る。Maxなら週間上限50%が恒久組み込み |
| 法人・経費精算あり | **Web 一択** | Anthropic 名義の領収書・インボイス対応 |
| Team / Enterprise | **Web / 営業経由のみ** | App Store では契約不可 |

> 最もコスパの良い構成は **「Web で契約して、iPhone アプリで使う」**（Max の場合）。契約経路とアプリの利用先は独立しています。

## 7. 注意点

- **契約経路の移管は不可** — iOS ⇄ Web の切り替えは「解約 → 新規契約」が必要
- **iOS の領収書は Apple 名義のみ** — 法人の経費処理・インボイスには不向き
- **為替で結論が変わる** — 9月も円高基調が続いており、**契約時のレートで再計算**を
- **iOS は為替ヘッジになる** — 円安に振れても価格が動かないのは iOS の利点。逆に円高では不利
- **Fable系のクレジット期限に注意** — Pro/Team Standardで無料枠のつもりで使い続けると、2026-09-17以降は気づかないうちに実費課金になっている可能性がある
- **課金分離は一時停止のまま** — 2026年6月15日施行予定だった Agent SDK / `claude -p` 等の課金プール分離は施行当日に一時停止され、9月時点でも再開されていない（比較への影響なし）

## まとめ

2026年9月の Claude プラン費用は、**「Pro月額はiPhone、それ以外はWeb」**という構図がさらに明確になりました。8月時点で互角だったPro年契約もWebが優位に転じ、Maxの差はさらに拡大しています。

そして9月最大のトピックは**Fable 5.1のリリース**です。モデル自体は魅力的な後継ですが、**サブスクプランでの費用構造はFable 5から変わっていません**。Pro/Team Standardで本格的に使うと、$100の一時クレジット（まもなく失効）を使い切った後はすぐに実費課金に入ります。**Fable系を継続的に使いたいならMax（またはTeam Premium）が前提**、という点を押さえておくことが、9月以降の費用管理で最も重要です。

最新の状況は冒頭の随時更新版2記事、Fable 5.1自体の詳細は専用記事で確認してください。
