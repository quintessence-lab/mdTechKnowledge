> ## 要点（2026年8月時点）
>
> - **Pro（月額）**: **iPhone（App Store）が微安**。iOS ¥3,000 固定 vs Web 実質 約¥3,450。**月 約¥450（約13%）iOS が安い**
> - **Max 5x / 20x**: **Web（claude.com）一択**。**月 ¥2,700〜¥5,500 Web が安い**。7月より差が**拡大**した
> - **拡大の理由は円高**: 8月上旬は**日米協調介入**を受けて $1≈¥157 前後（7月は約¥162.4）。Web のドル建て実質コストが下がった
> - **年契約は Web のみ有利**: Pro 年契約は Web $200 / iOS $214.99（+7.5%）。**Max の年契約は iOS に存在しない**
> - **法人・経費処理は Web 一択**（iOS は Apple 名義の領収書のみ）
> - 8月は**料金に効く期限が3つ**（8/17 Workbench 廃止・8/19 Claude Code 上限 +50% 終了・8/31 Sonnet 5 導入価格終了）

**前提（8月の固定値）**

| 項目 | 値 |
|:---|:---|
| 為替 | **$1 ≈ ¥157**（8月上旬の実勢。8/6 は約¥158.1、8/7 は¥158.39→¥156.68。週間レンジ想定 ¥156〜160） |
| Web の消費税 | **10%**（2026年4月以降、Anthropic が適格請求書発行事業者として加算） |
| iOS 円価格 | 2026年6月の **Apple 円ティア引き下げ後**（Pro ¥3,000・Max 5x ¥20,000・Max 20x ¥40,000、税込固定） |

> **8月上旬の為替は荒れました。** 日米当局による協調介入への警戒と実際の介入で一時 ¥155.21 まで急落し、米7月雇用統計の下振れでさらにドル売りが進む場面もありました。本記事は ¥157 を代表値としますが、**契約時点のレートで再計算する**ことをおすすめします。

## 1. 契約経路は2系統ある

| 経路 | 価格の性質 |
|:---|:---|
| **Web 直接契約**（claude.com） | Anthropic が定価で提供。**米ドル建て**請求＋消費税10%。為替の影響を受ける |
| **iPhone アプリ契約**（App Store） | Apple 手数料（標準30%）の影響で多くのプランが割高。**日本円固定ティア**（税込）で為替の影響を受けない |

機能は**完全に同等**です。Web で契約しても iPhone アプリ・デスクトップアプリで同一アカウントで利用できます。異なるのは**価格・請求通貨・領収書の名義**だけです。

なお **Team / Enterprise は App Store では契約できません**（Web・営業経由のみ）。iPhone アプリから契約できるのは Free / Pro / Max です。

## 2. 米国価格（USD）— 8月も据え置き

| プラン | Web 月額 | Web 年契約 | iOS 月額 | iOS 年契約 | iOS 割高率 |
|:---|:---|:---|:---|:---|:---:|
| Free | $0 | — | $0 | — | — |
| **Pro** | **$20** | **$17/月（$200一括）** | $20.00 | $214.99 | 月: 同額 / 年: **+7.5%** |
| **Max 5x** | **$100** | 月額のみ | **$124.99** | なし | **+25%** |
| **Max 20x** | **$200** | 月額のみ | **$249.99** | なし | **+25%** |

Apple 手数料の転嫁パターンはプランで異なります。

| プラン | Anthropic の対応 |
|:---|:---|
| Pro 月額 | **吸収**（Web と同額） |
| Pro 年契約 | **一部転嫁**（+7.5%） |
| Max 5x / 20x | **完全転嫁**（+25%） |

Max は利用者あたりの単価が大きく、Anthropic が手数料を吸収しきれないため価格に反映されています。**この USD 構造は為替が動いても変わりません。**

## 3. 日本価格（8月・$1≈¥157・税込実質）

| プラン | iOS（円固定・税込） | Web 実質（$×157×1.10） | 差 |
|:---|:---|:---|:---|
| Pro 月額 | **¥3,000** | 約 ¥3,450 | **iOS が約 ¥450 安**（約13%） |
| Max 5x 月額 | ¥20,000 | **約 ¥17,300** | **Web が約 ¥2,700 安** |
| Max 20x 月額 | ¥40,000 | **約 ¥34,500** | **Web が約 ¥5,500 安** |

### 7月からの変化 — 円高で Max の差が広がった

| プラン | 7月（$1≈¥162.4） | **8月（$1≈¥157）** | 変化 |
|:---|:---|:---|:---|
| Pro | iOS が約¥570 安 | **iOS が約¥450 安** | iOS 有利が**縮小** |
| Max 5x | Web が約¥2,100 安 | **Web が約¥2,700 安** | Web 有利が**拡大** |
| Max 20x | Web が約¥4,300 安 | **Web が約¥5,500 安** | Web 有利が**拡大** |

理由は単純で、**iOS は円固定・Web はドル建て**だからです。円高に振れると Web 側だけが安くなります。

- **Pro**: iOS 有利は続くが、幅は 約¥570 → 約¥450 に縮小。**$1≈¥136 を割る円高になると Web が逆転**します
- **Max**: もともと Web 有利だったところに円高が加わり、差が拡大。**年換算で Max 5x 約¥32,000・Max 20x 約¥66,000** の差になります

## 4. コストに関わる8月の期限

8月は**サブスク料金表そのものの改定はありません**が、費用や利用可能量に影響する期限が集中しています。

| 期日 | 内容 | 費用面の影響 |
|:---|:---|:---|
| **8月17日** | **レガシー Workbench 廃止**＋実験的プロンプトツールAPI 3本リタイア | 直接の費用増はないが、**保存済みプロンプト・変数・evals はエクスポートしないと失われる** |
| **8月19日** | **Claude Code 週間利用上限 +50% 措置の終了** | 月額は不変だが**使える量が通常水準に戻る**。実質的な「値上げ」に近い体感 |
| **8月31日** | **Sonnet 5 導入価格の終了**（$2/$10 → **$3/$15**） | API 利用者は**実質50%の値上げ**。サブスク月額には影響なし |

サブスク契約者にとって特に効くのは **8月19日** です。月額は変わらないまま Claude Code の週間上限が戻るため、ヘビーに使っている場合は「今週分を使い切るのが早くなった」と感じます。詳細は [Claude の2026年8月 移行期限まとめ](/mdTechKnowledge/blog/claude-august-2026-migration-deadlines/) を参照してください。

> 参考: 7月20日に決着した Fable 5 は、**Max / Team Premium では週間上限の50%として恒久組み込み**（追加費用なし）、**Pro / Team Standard は Usage Credits 継続＋一時 $100 クレジット**という扱いです。この $100 クレジットは**請求期限 2026-08-02 が既に経過**しており、有効期限は 2026-09-17 です。

## 5. どちらで契約すべきか（8月版）

| ユーザー像 | 推奨 | 理由 |
|:---|:---|:---|
| 個人 Pro（月額・コスト重視） | **iPhone アプリ** | ¥3,000 固定が Web 実質（約¥3,450）より月約¥450 安 |
| 個人 Pro（年契約を検討） | **Web** | 年契約は Web のみ割安（$200 vs $214.99） |
| 個人 Max（5x / 20x） | **Web 一択** | 月 ¥2,700〜¥5,500 安。iOS に年契約なし。円高で差は拡大中 |
| 法人・経費精算あり | **Web 一択** | Anthropic 名義の領収書・インボイス対応 |
| Apple にサブスクを集約したい個人（Pro） | iPhone アプリでも可 | 8月の為替でも金額面の不利はない |
| Team / Enterprise | **Web / 営業経由のみ** | App Store では契約不可 |

> 最もコスパの良い構成は **「Web で契約して、iPhone アプリで使う」**（Max の場合）。契約経路とアプリの利用先は独立しています。

## 6. 注意点

- **契約経路の移管は不可** — iOS ⇄ Web の切り替えは「解約 → 新規契約」が必要
- **iOS の領収書は Apple 名義のみ** — 法人の経費処理・インボイスには不向き
- **為替で結論が変わる** — 8月は介入をはさんで ¥155〜160 で振れました。**契約時のレートで再計算**を
- **iOS は為替ヘッジになる** — 円安に振れても価格が動かないのは iOS の利点。逆に円高では不利
- **課金分離は一時停止のまま** — 2026年6月15日施行予定だった Agent SDK / `claude -p` 等の課金プール分離は施行当日に一時停止され、8月時点でも再開されていない（比較への影響なし）

## まとめ

2026年8月の Claude プラン費用は、**「Pro は iPhone、Max は Web」**という7月からの住み分けが維持されつつ、**円高によって Max の Web 有利が拡大**した状況です。Max 20x では月 約¥5,500・年 約¥66,000 の差になり、契約経路の選択が最も効くプランになっています。

一方で8月は、料金表ではなく**期限**が費用体験を左右する月でもあります。特に8月19日の Claude Code 上限 +50% 終了は、月額据え置きのまま使える量が減るという形の実質的な負担増です。最新の状況は冒頭の随時更新版2記事で確認してください。
