> ## 要点
>
> - **現在地（2026年10月31日）**: Anthropic は **10月26日に公開の Form S-1 を SEC に提出**しました（File No. 333-299633）。**Nasdaq Global Select Market にティッカー「ANT」で上場申請**という枠組みまでは確定しましたが、**株数・想定価格・調達額は S-1 でも空欄**です。EDGAR を確認した時点で、S-1/A（修正）や 424B（目論見書）は出ていません。
> - **数字が初めて一次情報で出ました**: 2026年上期の売上は **$16.3B**（前年同期比 +1,300%）、純損失は **$80.7B**。ただし純損失の大半（**$72.4B**）は転換社債などの**公正価値変動**という会計上の項目で、営業損失は **$0.7B** です。
> - **ガバナンスは三層**: PBC（公益法人）であること、LTBT が持つ **Class T 株**で取締役会の過半を選ぶこと、共同創業者の **Founder LLC が議決権の 50.1%**（Class F 株）を持つこと。6月時点の「創業者が支配を手放す」という整理は、そのままでは通用しなくなりました。
> - **報道と S-1 は一致しない部分があります**。「上位2社で売上25%」は誤りで、S-1 は「**上位5社で約25%、単独で10%を超える顧客はなし**」です。評価額や上場日の数字は、**いずれも報道ベース**です。

## 2. 公開 S-1 で確定したこと・空欄のままのこと

### 確定したこと

- **上場先とティッカー**: Class A 普通株式を **Nasdaq Global Select Market** に「**ANT**」で上場申請。Nasdaq の統治基準上の **controlled company（支配会社）** に該当し、一部の統治要件が免除されると記載されています。
- **主幹事**: Goldman Sachs、Morgan Stanley、J.P. Morgan、Citigroup、Barclays、Wells Fargo Securities、BofA Securities、Deutsche Bank Securities、RBC Capital Markets の9社。
- **売出しの構成**: 会社による売出しと、既存株主による売出しの両方を含む構成です。

## 3. 論点① ガバナンス — PBC × LTBT × 創業者の議決権

S-1 から読める構造は、次の表のとおりです。

| 株式クラス | 内容（S-1 の記述） |
|:---|:---|
| Class A | 1株1議決権。公募の対象 |
| Class N | 議決権なし（法律上必要な場合を除く）。主に戦略的事業パートナーが保有 |
| Class T | **LTBT が保有する特別株**。Class T 取締役（取締役会の過半数）を選任・解任できるが、それ以外の議決権・経済的権利はない |
| Class F | 公募直前に、共同創業者が組成する **Founder LLC に1株**を発行。Class T 取締役の選任を除く事項で、**議決権の合計の 50.1%** を持つ。経済的権利はない |
| Class E | 共同創業者を除く従業員向け。限られた事項のみ議決権があり、経済的権利はない |

これを、6月時点の整理と照らすと次のようになります。

- 6月の記事では「創業者がデュアルクラス株で支配を握る通常のテック企業とは**逆**に、権限を LTBT に委譲する」ことが特徴とされていました。
- 9月25日の報道（The Information）で、創業者7名の合計 50.1% の議決権確保が報じられ、10月の S-1 で **Class F・Founder LLC という形で具体化**されました。
- つまり、**LTBT による取締役の選任（Class T）と、創業者による議決権の保持（Class F）が併存**する設計です。ミッションの番人と創業者の支配が、別々の株式クラスで両方確保されています。
- 会社の法形式は Delaware 法の **PBC**。株主の金銭的利益、事業の影響を受ける人々の最善の利益、定款の公益目的（「人類の長期的利益のための高度な AI の責任ある開発と維持」）を均衡させる義務を負うと明記されています。

> **公開市場の投資家にとっての論点**（本稿の整理）: 新規に買う株主は、Class A という「議決権が相対的に薄い株」を持つことになります。ミッション保全を優先する設計を評価するか、ディスカウント要因とみなすかが、価格形成の論点です。S-1 は controlled company であることも認めているため、一部の統治要件が適用されない点も確認が必要です。

## 4. 論点② Public Benefit Fund — 株式の5%を公益に

2026年10月18日の発表と、10月26日の S-1 の記述を合わせると、次のように読めます。

| 項目 | 内容 |
|:---|:---|
| 構造 | Anthropic の完全子会社である LLC（Anthropic Public Benefit Fund, LLC） |
| 初期拠出 | 2026年6月30日時点の完全希薄化後株式（Amazon Notes の全額転換を仮定）の **5% = 846,840,960 株の Class N 株** |
| 追加発行の枠組み | **株価が前のマイルストーンから50%上昇するごとに、発行済株式の最大2%**を追加で発行できる枠組みを取締役会が承認済み。起点は **IPO 価格** |
| 政治利用の禁止 | 保有株式はロビー活動や政治献金に使わない（10月18日の発表） |
| 関連する誓約 | 共同創業者がそれぞれ個人持ち株の 80% を慈善目的に拠出すると誓約 |

なお、10月18日の発表時点では「基準値は明示されていない」とされていましたが、S-1 で**起点が IPO 価格**と分かりました。拠出は株主承認が前提とされています。

## 5. 論点③ 財務 — 売上の急拡大と、巨額の純損失の中身

S-1 の連結損益データ（単位: 百万ドル）です。

| 項目 | 2023 | 2024 | 2025 | 2025年上期 | 2026年上期 |
|:---|---:|---:|---:|---:|---:|
| 売上高 | 41 | 386 | 4,585 | 1,163 | **16,286** |
| 計算資源・インフラ費 | 433 | 2,522 | 7,326 | 2,334 | 8,945 |
| 営業損失 | (551) | (2,980) | (8,060) | (2,135) | (693) |
| 転換社債・デリバティブ・SAFE の公正価値変動 | (1,045) | (5,434) | (34,308) | (10,942) | (72,388) |
| 純損失 | (1,531) | (8,309) | (41,965) | (12,969) | **(80,748)** |

**読み取れること**

1. **売上は倍々どころではない**: 2026年上期は前年同期比 **+1,300%**（S-1 の表現）。報道されていた Q2 売上「$11.5B 超」と、Q1 の社内予測として報じられた約 $4.8B を足すと約 $16.3B で、S-1 の上期売上と整合します（本稿の足し算）。
2. **純損失の見た目は大きいが、中身は会計項目が中心**: 2026年上期の純損失 $80.7B のうち **$72.4B は転換社債などの公正価値変動**です。企業価値が上がると転換社債の評価額が増え、会計上は損失として計上されます。**営業損失は $0.7B** と、前年同期の $2.1B から縮小しています。
3. **「黒字」の報道との違い**: 報道では「Q2 に調整後営業利益 $559M の黒字」とされていました。S-1 の営業損失は上期通算の数字で、**指標の定義が違う**ため、そのまま突き合わせはできません。
4. **売上構成**: 2026年上期は従量課金（consumption-based）が **80%**、サブスクリプションが **20%**（2025年は 83%・17%）。
5. **計算資源費は売上の約55%**: 2026年上期で $8.9B（本稿の割り算）。粗利率「80%超」という報道は、学習コスト控除前などの条件付きだったため、S-1 の数字と同じ土俵では比べられません。
6. **訴訟和解の影響**: Bartz 和解の $1.5B は2025年の費用に含まれます。

**資金**: 2026年6月30日時点で、累計調達額 **$141.1B**、現金同等物 **$112.4B**、短期投資 **$19.3B**。

> S-1 に載っていない数字は採用していません。たとえば「Q3 売上 $16.8B」という数字は、一次情報が見つからなかったため、本稿では扱いません。

## 6. 論点④ コンピュートという長期固定費

売上が急拡大する一方で、**計算資源の確保は長期・固定の契約**で行われています。コンピュート契約の全体像は [別記事](/mdTechKnowledge/blog/anthropic-compute-deals-2026/) にまとめていますが、上場の文脈で押さえるべき点は次の4つです。

- **契約期間が長い**: 公式発表・取引先の開示で確認できるものだけでも、Amazon は **10年で $100B 超**の AWS コミット（最大 5GW）、TeraWulf は 20年・401MW・約 $19B、Riot は 20年・191MW・約 $9.1B（借り手名は開示文書にはなく、報道が Anthropic と特定）、AMD は最大 2GW、Google・Broadcom は複数ギガワット級の TPU です。
- **稼働は2027年に集中**: 契約の多くは2027年以降の需要に向けた**先行確保**です。需要見通しが外れた場合の負担は、IPO に向けた財務の論点になります。
- **資金調達が複線化**: 株式（Series H の $65B）、戦略投資（Amazon・Google・AMD）、銀行のクレジット枠（IPO 前の回転信用枠は $15B 規模と報道）、そして SPV を通じたチップリースがあります。SPV 経由のチップリース債務は、**60日間で約 $71B** を積み上げ、貸借対照表に載らない形だと報じられています（報道ベース）。S-1 での扱いは、本稿では未確認です。
- **戦略は自社データセンターを持ちすぎない**: Daniela Amodei は6月のインタビューで、モデルの学習と推論には巨額の先行投資が必要で、「公開市場はそれに非常に適している」と述べています。

> **M&A との関係**: 2026年の買収・買収交渉（Bun・Vercept・Stainless など）は、[別記事](/mdTechKnowledge/blog/anthropic-acquisitions-2026/)のとおり金額が公式には非開示です。約 $6B の Decart 買収交渉は、9月上旬に Anthropic が撤退したと報じられました。上場前の大型 M&A は成立していません。

## 7. 論点⑤ 顧客集中・法的リスク・世論

- **顧客集中**: S-1 によれば、**単独で売上の10%を超える顧客はなく**、上位5社で2026年1〜9月の売上の約 25% です。年間売上 $100,000 以上の顧客は、2025年9月30日の 950 超から、2026年9月30日の **11,900 超**に増えました。
- **訴訟**: 著作権集団訴訟（Bartz）の $1.5B 和解は確定済みです。7月に表面化した商標訴訟（対 Abnormal AI）、Claude Max の使用量表示をめぐるクラスアクション、インドでの商標紛争は、いずれも**報道・提訴段階の主張**で、S-1 の Legal Proceedings・Risk Factors での扱いは本稿では未確認です。
- **世論**: CNBC は8月、目論見書に「AI バックラッシュ」とデータセンター建設への反発がリスク要因として明記される見通しと報じました（報道ベース）。計算資源の確保が事業の前提であるため、データセンターへの反対は事業リスクに直結します。
- **政府調達**: 国防総省による「サプライチェーン・リスク」認定の報道が、収益リスクとして指摘されています（報道ベース）。

## まとめ

- Anthropic の上場計画は、**6月の機密ドラフト → 5回の修正 → 10月26日の公開 S-1** と進み、**Nasdaq「ANT」への上場申請**という形までは確定しました。
- **売上は急拡大**し、営業損失も縮小していますが、純損失の大半は転換社債の公正価値変動という会計項目です。売上と損失の「見た目」だけで判断しないことが重要です。
- **ガバナンス**は、PBC・LTBT の Class T・創業者の Class F（議決権 50.1%）が併存する設計で、公開市場の投資家はこれをどう値付けするかが焦点になります。
- 一方で、**株数・価格・調達額・上場日は未確定**です。評価額や日程の数字は報道ベースにとどめ、次の S-1/A で確定する情報を確認するのが筋です。
